# AI Interviewer 🎯

An AI-powered interview practice platform built with Python and Streamlit. It analyzes resumes, detects technical skills, conducts role-based interviews, evaluates candidate answers, and provides a detailed performance report.

## 🚀 Features

- 📄 Resume PDF upload and text extraction
- 🧑‍💻 Technical skill detection
- 📋 Resume summary and analysis
- 🎯 Role-based interview questions
- 💬 Conversation-style interview experience
- ⏱️ Question timing and answer tracking
- 🧠 Answer evaluation
- 📊 Technical, relevance, clarity, and practical understanding scores
- 💪 Candidate strengths and improvement areas
- 📚 Recommended practice topics
- 📈 Resume readiness and role-skill matching
- 🎉 Final interview performance report

## 🛠️ Technologies Used

- Python
- Streamlit
- PyPDF
- Pandas
- OpenAI API
- Regular Expressions
- Git & GitHub

## 🎯 Supported Interview Roles

- AI / ML Engineer
- Data Scientist
- Python Developer
- Software Developer
